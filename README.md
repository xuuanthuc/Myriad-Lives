# Myriad Lives

Khung React + Vite cho website **Myriad Lives** — một trải nghiệm random tu tiên.

## Chạy cục bộ

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Triển khai (hosting tùy chọn)

Chạy lệnh sau để tạo thư mục tĩnh `dist/`:

```bash
npm run build
```

Sau đó upload nội dung thư mục `dist/` lên nền tảng hosting bạn chọn. Không có workflow GitHub Pages trong dự án.
