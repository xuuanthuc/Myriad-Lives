# Event backgrounds

Generated with the built-in imagegen tool. Optimized WebP assets for the timeline; text is supplied by the UI, never baked into the artwork.

Shared prompt: stylized Chinese ink wash watercolor on warm ivory rice paper, airy low-contrast brushwork, panoramic composition with detail on the right third and empty mist on the left for readable text. No text, UI, border or watermark.

- `danger.webp`: stormy mountain gorge, distant sword, crimson mist, muted terracotta.
- `choice.webp`: two winding mountain paths, solitary robed traveler at the fork, muted ochre gold.
- `breakthrough.webp`: meditating cultivator atop a peak, luminous circular aura and rising clouds, muted jade teal.
- `ending.webp`: ancient tree, fading mountain sunset, drifting leaves and empty path, muted slate violet.
