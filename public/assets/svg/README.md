# SVG icons

Thêm các file SVG vào thư mục này để dùng làm icon trong giao diện.

Tên gợi ý:

- `arrow-right.svg`: mũi tên sang phải trong các nút.
- `arrow-up-right.svg`: mũi tên chéo trong nút Cách chơi.
- `chevron-down.svg`: mũi tên mở rộng.

Vite phục vụ file từ `assets/svg/<tên-file>.svg`.

Đang dùng `angles-up-solid-full.svg` và `angles-down-solid-full.svg` qua `src/components/ArrowIcon.jsx`. Hướng phải và chéo phải dùng bản lên được xoay bằng CSS. Icon lấy màu theo nút, giữ nguyên file SVG cùng chú thích bản quyền gốc.
